# 今夜のベストペア！ 🍶✨

- !(pictures/Osake.png)

「今夜のベストペア！」は、**お酒とおつまみの新しい組み合わせ（ペア）**を気軽に見つけられるサイトです。

公式サイト
- https://team-osake-07-todays-best-match.netlify.app/

---

## サイトの特徴
- 簡単：ジャンルを選んで「マッチを探す」をクリックするだけでおすすめが表示されます。
- 見やすい：各組み合わせはカード形式で表示され、説明や強調ポイントが一目で分かります。
- 出典が分かる：カードには出典（リンク）が付いており、元情報をすぐに確認できます。
- 情報の元は各種ホームページ：組み合わせの候補はメーカー公式サイトや商品紹介ページ、飲食情報サイトなど、複数のホームページを参照して収集しています。
- 新しい発見ができる：普段出会わないような組み合わせも提案され、気軽に新しい味の発見ができます。

---

## 使い方
1. ホームページにアクセスします。
2. お酒のジャンル（例：ビール、ワイン、ウィスキーなど）を選びます。
3. 「マッチを探す」を押すと、おすすめの組み合わせカードが表示されます。
4. 気になるカードの出典リンクをクリックすると、元の情報ページを確認できます。

---

## データの扱いについて
- 組み合わせ候補は、信頼できる各種ホームページ（メーカー公式・商品ページ・飲食情報サイト等）を参考にしています。
- 各カードに「出典」リンクを付けているため、どの情報を基にした提案かをユーザー自身で確認できます。
